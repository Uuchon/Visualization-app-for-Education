INPUT
START 「マイク」「ファイル」「テスト音」のどれかを押す → 円の色と大きさの変化を見る → 「くわしく見る」「設定」で調べる

01色に対応させる周波数（Hz）

音の高さを、どの範囲で赤〜紫に対応させるかを決めます。広い画面では、右のプレビューに設定がすぐ反映されます。

02音量・校正

画面のphonは相対値です。色がうすい・暗いときは、大きめの声で「自動で合わせる」を押してください。

03ノイズ除去

音声ファイルは音そのものから雑音を引きます。マイクは、静かにして登録した環境ノイズ（エアコン・外の音など）を、色やグラフの解析から引きます。

04表示

低い音を細かく見たいときは「高」「最高」。反応は少しゆっくりになります。
